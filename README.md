# Supplement_Sales_analysis
Data analytics project showcasing supplement sales analysis using Power BI

Overview

This project focuses on analyzing supplement sales data using Power BI. It covers the complete data analytics workflow — from data loading and cleaning to building interactive dashboards and presenting insights.

The goal is to extract meaningful business insights and visualize sales performance across products, platforms, and regions.

📂 Dataset

The dataset contains sales information for supplement products, including:

Product Name
Category
Platform (Amazon, Walmart, iHerb)
Location (Canada, UK, USA)
Revenue
Units Sold
Total Profit
Date
🛠️ Tools & Technologies
Power BI – Data visualization and dashboard creation
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – Calculations and time intelligence
Gamma AI – Presentation (PPT) creation
⚙️ Steps Followed
1. Data Loading
Imported dataset into Power BI
2. Data Cleaning (Power Query)
Removed duplicates
Handled missing values
Standardized column formats
Converted Date column to proper format
3. Data Transformation
Created structured data model
Built a Date Table for time-based analysis
Established relationships between tables
4. DAX Calculations
Created measures like:
Total Revenue
Total Profit
Yearly Sales
Quarterly Sales
5. Dashboard Development
Designed interactive visuals and KPIs
Added filters and slicers for dynamic analysis
6. Reporting & Presentation
Generated insights report
Created presentation using Gamma AI
📊 Dashboard Highlights
KPI Card: Total Revenue overview
Sales by Platform: Comparison across Amazon, Walmart, iHerb
Product Performance Table: Top-selling products
Category Analysis: Sales and profit trends
Location Filter: Region-wise analysis
📈 Results & Insights
Achieved total revenue of 22.91M
Balanced contribution across platforms
Identified top-performing products like Ashwagandha, BCAA, Biotin
Highlighted high-performing categories and areas for improvement
